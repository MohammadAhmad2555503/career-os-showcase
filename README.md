# Career OS Showcase

Local-first career intelligence system with Career Brain, Project Brain, evidence-grounded job ranking, Truth Audit, safe apply automation, and strong release verification.

## Why It Matters

Career OS is built around a serious product insight: job-search software should maximise truthful career outcomes, not application spam. It treats professional claims as evidence-bound objects, keeps hard constraints ahead of ranking, and stops automation before risky or unsupported actions.

## Employer-Relevant Highlights

- Local-first architecture with no required paid APIs.
- Career Brain for profile, skills, goals, preferences, CV ingestion, and explicit verification.
- Project Brain for static project import, secret scanning, cited code search, claim extraction, and contribution verification.
- Evidence-aware ranking pipeline with hard-filter decisions and feedback learning.
- Truth Audit for generated CVs, cover letters, and application answers.
- Assisted Apply and Autopilot paths with conservative safety gates.
- FastAPI product layer plus TypeScript command-centre UI.
- Release evidence includes 95 tests, 21 modules, E2E verification, adversarial checks, and a 100,000-job scale gate.
