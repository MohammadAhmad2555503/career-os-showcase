# Resume Bullets: Career OS

- Built a local-first career intelligence system combining CV ingestion, Project Brain static analysis, evidence verification, job ranking, Truth Audit, application generation, interview preparation, offer analysis, and career growth tracking.
- Designed privacy and safety controls including local-only defaults, project secret scanning, prompt-injection filtering, verified-evidence lifecycles, hard-filter enforcement, and dual-gated application automation.
- Validated the release candidate with 95 tests across 21 modules, a fresh E2E workflow, adversarial Truth Audit checks, prompt-injection/ATS safety gates, backup/restore validation across 47 tables, and a 100,000-job ranking benchmark.
